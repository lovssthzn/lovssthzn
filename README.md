### 🚀 Projetos

*   **⏱️ Ponto Online:** Arquitetura de registro de ponto desenvolvida com React, Supabase e n8n, incluindo campos de entrada manual por botão de ação para controle preciso.
*   **💬 Bot de Consulta de Crédito:** Robô para WhatsApp focado na extração de documentos e qualificação de leads, utilizando lógica de roteamento em três vias (enviado, não enviado, dificuldade técnica).
*   **🤖 Automação Shopee:** Scraper em Python aliado ao n8n para filtragem e distribuição automática de produtos de afiliados diretamente em grupos do WhatsApp.
*   **🏦 Navegação Bancária Automatizada:** Scripts de Playwright integrados para operar os portais V8 e Banco Mercantil na simulação de crédito e emissão de consentimentos.
*   **📦 Deploy Independente:** Migração de um projeto web criado no Lovable para uma arquitetura totalmente autônoma usando Vite, Vercel e Supabase.
